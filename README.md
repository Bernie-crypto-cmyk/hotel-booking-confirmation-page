# hotel-booking-confirmation-page
**Description**

This a confirmation page of a hotel after reservation.It contains a menu and hover card at desktop view.

**technologies used**
1. html
2. css
3. javascript

**What I learned**
1. I learned how to apply grid display to different elements and give a bento grid look.
2. I learned to apply basic animation.

**Future Improvements**
1. adding a full js functionality on the copy password
2. Add a working copy button so guests can copy the Wi-Fi password in one click
3. Make the sidebar navigation collapse into a toggleable menu on smaller screens
4. Animate the receipt and host-note cards so they fan out on hover
5. Wire up the "Print receipt" button to open a clean print view using the browser's print dialog
6. Generate an "Add to calendar" file from the stay dates so guests can save their booking
7. Load the booking details from a JSON file instead of hardcoding them
